# TOC

Учебный веб-симулятор производственной системы по Теории ограничений. Проект предназначен для самостоятельного обучения студентов через песочницу и объясняющие сценарии.

Подготовлены концепт, план и первая очередь задач. Реализованы основа React/TypeScript/Vite/Vitest и первая автономная сборка с минимальным SVG и переключением RU/EN. Добавлены независимые от DOM модули точной арифметики, проверки линейной конфигурации, неизменяемого RunConfig и снимков состояния. Реализованы FIFO, перенос, резервирование и выпуск с сохранением стоимости и происхождения. Добавлен производственный календарь с обедом, переносом операций и точным горизонтом. Добавлена событийная основа с согласованным шагом и защитой от устаревших завершений. Источники push связаны с календарём, очередью и общим складом. Работает независимая от DOM детерминированная линия с обработкой, буферами, календарными паузами и физическим выходом. На странице она пока не отображается.

Сборка создаёт самостоятельный `dist/index.html`. Его можно скопировать отдельно и открыть в браузере двойным щелчком без сети и сервера. Тот же файл можно разместить на статическом хостинге, в том числе в подкаталоге. Node.js и npm нужны только для сборки из исходников.

## Основные решения

Используемый стек: TypeScript, React и Vite. Автономная однофайловая сборка реализована через vite-plugin-singlefile 2.3.4. Будущий движок использует дискретно-событийную модель и не зависит от интерфейса. Несколько материалов, рецепты, сборка и разделение потоков входят в первую версию.

Входные и выходные буферы настраиваются у постов и наследуют глобальные значения, если не переопределены. Вариативность воспроизводится через seed. Конфигурация фиксируется при старте; изменения проверяются новым прогоном, в том числе через A/B. Длительность выбирается для конкретного урока или эксперимента.

Схема должна наглядно показывать движение материала, рост очередей, загрузку и причины простоя. Ускорение, пауза и шаг позволяют наблюдать поток и разбирать его причины без обязательного перехода к графикам.

Git-репозиторий инициализирован локально. Для чтения документов устанавливать зависимости не требуется.

После завершения каждой задачи изменения проверяются и фиксируются Git-коммитом. Push и публикация требуют отдельного поручения.

Работа выполняется ровно по одной задаче. Перед следующей требуется ответ пользователя на вопрос о её запуске.

Перед задачей оценивается её объём; для большой реализации предлагается разбиение на подзадачи. Основной принцип: «НЕ ПЕРЕУСЛОЖНЯТЬ!». Подробные правила находятся в `agents.md`.

## Разработка

Используется Node.js 24.15.0, указанный в `.nvmrc`, и npm 12.1.0. Прямые зависимости зафиксированы точными версиями, полный состав зависимостей находится в `package-lock.json`.

Из корня проекта выполнить:

```sh
npm ci
npm run dev
```

Dev-сервер доступен только локально. Адрес выводится в терминале. Это способ работы разработчика; готовый `dist/index.html` открывается без сервера.

| Команда | Назначение |
|---|---|
| `npm run dev` | Запуск Vite для разработки |
| `npm run typecheck` | Строгая проверка TypeScript без генерации файлов |
| `npm test` | Однократный запуск тестов Vitest |
| `npm run test:watch` | Vitest с повторным запуском при изменениях |
| `npm run build` | Проверка типов и production-сборка в `dist/` |
| `npm run preview` | Локальный просмотр уже собранного `dist/` |

Команда `npm test` выполняет 218 тестов модулей и сквозной симуляции. Точная арифметика описана в [doc/ARITHMETIC.md](doc/ARITHMETIC.md), формат конфигурации в [doc/CONFIGURATION.md](doc/CONFIGURATION.md), материальный учёт в [doc/INVENTORY.md](doc/INVENTORY.md), календарь в [doc/CALENDAR.md](doc/CALENDAR.md), событийная основа в [doc/EVENTS.md](doc/EVENTS.md), источники в [doc/SOURCES.md](doc/SOURCES.md), работающая линия и её API в [doc/SIMULATION.md](doc/SIMULATION.md).

Для получения HTML выполнить `npm ci`, затем `npm run build` и открыть `dist/index.html`. При распространении достаточно одного файла. Хранение данных для текущей страницы не требуется.

В № 9 проверены TypeScript, production-сборка и работа HTML в Google Chrome через `file://` без сети и HTTP в подкаталоге. Подробности, версия браузера и ограничения находятся в [doc/AUTONOMOUS_BUILD_CHECK.md](doc/AUTONOMOUS_BUILD_CHECK.md).
