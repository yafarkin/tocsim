# TOC

Учебный веб-симулятор производственной системы по Теории ограничений. Проект предназначен для самостоятельного обучения студентов через песочницу и объясняющие сценарии.

Подробный концепт подготовлен. Код приложения ещё не создавался.

Планируемый результат сборки представляет собой самостоятельный HTML-файл, который открывается локально в браузере и может размещаться на GitHub Pages. Интерфейс будет доступен на русском и английском языках.

## Основные решения

Предлагаемый стек: TypeScript, React и Vite с автономной однофайловой сборкой. Движок использует дискретно-событийную модель и не зависит от интерфейса. Несколько материалов, рецепты, сборка и разделение потоков входят в первую версию.

Входные и выходные буферы настраиваются у постов и наследуют глобальные значения, если не переопределены. Вариативность воспроизводится через seed. Конфигурация фиксируется при старте; изменения проверяются новым прогоном, в том числе через A/B. Длительность выбирается для конкретного урока или эксперимента.

Схема должна наглядно показывать движение материала, рост очередей, загрузку и причины простоя. Ускорение, пауза и шаг позволяют наблюдать поток и разбирать его причины без обязательного перехода к графикам.

Git-репозиторий инициализирован локально. Приложение пока не собрано, запускать или устанавливать зависимости для чтения концепта не требуется.

После завершения каждой задачи изменения проверяются и фиксируются Git-коммитом. Push и публикация требуют отдельного поручения.

Перед задачей оценивается её объём; для большой реализации предлагается разбиение на подзадачи. Основной принцип: «НЕ ПЕРЕУСЛОЖНЯТЬ!». Подробные правила находятся в `agents.md`.
