## Изменения интерфейса

В FlowDiagram под схемой раскрывается словарь «Вход», «Резерв», «Готово» и «Ждёт выгрузки». Он объясняет разницу между очередью и полным резервом партии, между готовым выпуском на посту и выходным буфером, между накоплением до порога и блокировкой разрешённой выгрузки. Все определения доступны на RU/EN. SVG title получает одну строку вместо массива текстовых узлов, чтобы подписи маршрутов, входов и передач корректно выводились React.

Новый RunSummary использует только готовые данные RunnerView. При ready/running/paused итог не показывается. При finished причина означает достижение заданного горизонта; при stopped показана остановка пользователем, при error показаны ошибка и её локализованное сообщение. Начало интервала соответствует нулю модели, конец берётся из фактического model.timeMs, а не из планового горизонта. Миллисекунды сохраняются, если они ненулевые.

По каждому конечному продукту отдельно показаны produced и sold. Первая колонка считает новые изделия прогона, в том числе ещё не выгруженные. Вторая считает годные изделия, переданные в готовую продукцию. Начальный готовый запас может попасть во вторую колонку без производства в текущем прогоне. Под таблицей есть пояснение различия. Количества разных продуктов не складываются. Финансовые показатели, история прогонов и новые метрики не добавлены.

При новом прогоне итог удаляется. Смена языка переводит текущий итог без нового расчёта. Внизу страницы видны приложение 0.1.0 и движок 0.11.0. Версия приложения импортируется из package.json через resolveJsonModule, версия движка берётся из текущего RunConfig. Дополнительный сетевой запрос не нужен. RNG counter32-fixed-lognormal-1 и Snapshot 9 сохранены.

Три новых теста RunSummary проверяют скрытие до окончания, раннюю остановку с точностью до миллисекунды и без подстановки горизонта, начальный готовый запас, два разных конечных продукта и локализованное сообщение ошибки. Прежние проверки расчёта и воспроизводимости проходят.

Chrome по HTTP подтвердил:

- Пояснения четырёх подписей доступны на RU/EN, версии совпадают с источниками в проекте.
