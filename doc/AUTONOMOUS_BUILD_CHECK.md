# Проверка первой автономной сборки

Дата: 2026-10-20. Задача № 9. Среда: macOS arm64, Node.js 24.15.0, npm 12.1.0. Браузер: установленный Google Chrome 155.0.8059.80, headless через временный Playwright. Playwright не добавлен в зависимости проекта.

## Сборка

Выполнены `npm run build` (включая строгую проверку TypeScript) и `npm ls --depth=0`. Ошибок нет. В `dist/` находится только `index.html`, примерно 223.5 kB до сжатия. JS и CSS встроены через vite-plugin-singlefile 2.3.4. Его peerDependencies допускают Vite 8; фактическая сборка с Vite 8.3.4 прошла. Версии сохранены в package-lock.json.

Словари находятся в исходном модуле React, SVG задан непосредственно в JSX. Используется системный шрифт. Внешних словарей, шрифтов и изображений нет.

## Браузерная проверка

| Проверка | Результат |
|---|---|
| `file:///Users/yafarkin/Documents/dev/TOC/dist/index.html`, offline-контекст | Страница открылась, переключение RU → EN → RU работает |
| `http://127.0.0.1:5199/nested/toc/index.html` | Тот же HTML работает в подкаталоге без отдельных ресурсов |
| Запросы страницы в каждом режиме | Только исходный HTML; дополнительных запросов нет |
| Ошибки JavaScript | Нет |
| Язык | Меняются тексты, подписи и доступное описание SVG, атрибут html.lang и заголовок вкладки |
| Внешние ресурсы в DOM | Нет script[src], внешних stylesheet, modulepreload, img[src] и iframe |
| Экран шириной 320 px | Горизонтального переполнения нет, сделан и просмотрен снимок страницы |

При визуальном просмотре уточнены стрелки: каждому из двух переходов назначен отдельный SVG path с наконечником. Схема статичная и прямо подписана как пример. Рабочих постов, движения и расчётов симуляции пока нет.

Для повторной ручной проверки собрать проект, открыть HTML отдельно от исходников и отключить сеть. Переключить оба языка, проверить подписи SVG и журнал запросов. Затем поместить тот же HTML в подкаталог статического сервера и повторить действия. При клавиатурном использовании доступны обычные кнопки с видимым фокусом и aria-pressed.

Автономность подтверждена для текущей минимальной страницы; после добавления механик её нужно проверять повторно. Продуктовых тестов движка пока нет.
