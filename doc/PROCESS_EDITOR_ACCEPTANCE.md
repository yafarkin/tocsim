План и границы: [PROCESS_EDITOR_MVP.md](PROCESS_EDITOR_MVP.md). Новых возможностей и изменений движка в приёмку не добавлено, ошибок приложения не найдено.

## Среда и основной путь

Живая проверка проведена в Google Chrome 156 через установленный пользователем Playwright Extension и MCP. Сборка размещена локально по HTTP в подкаталоге /lesson/ на отдельном тестовом origin 127.0.0.1:5186. Начальная библиотека этого origin была пуста. Чужие процессы не изменялись.

Создан исходный процесс 3/8/3 минуты, добавлен четвёртый пост, перемещён выше и обратно, затем удалён. После сохранения у оставшихся постов сохранились ID s1/s2/s3. Создана и сохранена независимая копия с постом 2 по 6 минут. После перезагрузки обе записи восстановились, исходник сохранил время 8 минут.

Проверены неполное число, сообщение и признак ошибочного поля, отказ сохранения без изменения revision, отмена перехода через Escape, сохранение перед переходом и отбрасывание нового черновика. Диалог при открытии фокусирует отмену; Shift+Tab возвращает фокус на последнюю кнопку. Отдельный процесс создан, назван, сохранён и удалён с помощью Tab, Shift+Tab и Enter. В цепочке из одного поста удаление заблокировано; после добавления до 30 постов добавление заблокировано. Цепочка из 30 постов сохранена, отмена удаления сохранила запись, подтверждение удалило только её.

## JSON

Настоящий экспорт исходника сохранён пользователем в Downloads через штатное окно Chrome. Файл 5316 байт содержит только format=toc-process, schemaVersion=1 и config. Снимков, результатов, revision и updatedAt в оболочке нет. Скачанный файл скопирован в разрешённую рабочую папку инструмента и выбран настоящим файловым полем импорта.

Проверены предварительный просмотр с условиями и буферами, отмена без изменения библиотеки, некорректный JSON и неизвестная версия без изменения записей. Принятый импорт создал новые ID записи и конфигурации. Остальные условия совпали с экспортом целиком, включая внутренние ID. Повторный запуск импортированного исходника дал те же 59 изделий.

Для файлового выбора Chrome сначала вернул DOM.setFileInputFiles: Not allowed. Пользователь включил у Playwright Extension доступ к URL файлов, после чего настоящий выбор файла через MCP заработал. Это ограничение расширения, а не исправление приложения. Пример причины описан [разработчиком Playwright](https://github.com/microsoft/playwright-mcp/issues/1481). Разрешение не включалось агентом скрытно.

## Отказы хранения

Внешнее изменение revision вызвало конфликт без перезаписи браузерной записи; явное перечитывание восстановило внешнюю версию. При искусственном отказе setItem по квоте новая версия осталась в памяти, интерфейс не назвал её сохранённой в браузере. После восстановления записи повторное сохранение прошло с revision 3.

Повреждённая запись и версия 99 не помешали открыть три корректных процесса и не были затёрты; тестовые повреждённые ключи удалены после проверки. При полном отказе доступа к localStorage в отдельной вкладке библиотека и сохранение работали в памяти, прогон дал 59. Эти отказы создавались только в тестовой странице; изменения методов Storage восстановлены.

Полный локальный npm run ci прошёл: 1649 тестов в 85 файлах, TypeScript/build/check:dist. HTML 706136 байт, SHA-256 3c9af6c330e96dfe19f01ce6d2cc5160fe42a7b27451b05c66dc946625d65068.
