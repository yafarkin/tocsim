## Контракт № 59

Необязательное поле EditorConfig.bufferDefaults содержит input и/или output. Оба глобальных значения принимают quantity с десятичной строкой либо infinite. Единое значение применяется независимо к каждому разрешённому материалу соответствующего буфера, не является суммарным лимитом всех материалов.

StationConfig.inputBuffer/outputBuffer остаются обязательными. Значение inherit выбирает глобальное правило для этого направления. Своя quantity/infinite или materials полностью переопределяет соответствующий вход либо выход поста, не меняя другое направление. materials перечисляет каждый материал плана ровно один раз, с собственной quantity/infinite. Неизвестные/повторные/пропущенные материалы отклоняются. Наследование отдельных элементов внутри materials не добавлено.

Пример: глобальный вход 10, вход первого поста inherit, второго quantity 30. Изменение глобального значения на 15 даёт 15 и 30. Явные значения не перезаписываются. Сброс переопределений и команды применения относятся к панели № 61, сейчас конфигурация передаётся в compileConfig.

Если глобального output нет, inherit даёт 0, как в концепте. Наследуемый input без явного bufferDefaults.input пока выдаёт ConfigError RU/EN с исходным путём поста. Это временная граница до № 60: расчёт default на 0.5 смены не реализован и не заменяется молча другим значением. kind=shift пока отклоняется. Прежние конфигурации с явными ёмкостями продолжают работать.

Компилятор проверяет глобальные значения даже без наследующих постов, разрешает правила до создания состояния, проверяет достаточность входного комплекта и начальные запасы. Недостаточное явное/наследованное количество не повышается молча. Исходная конфигурация копируется отдельно и хранит правила bufferDefaults/inherit/materials. Глубоко замороженный resolved содержит числовые inputBuffers и outputBuffers, отсортированные по materialId. Равные числовые результаты дают один calculationHash независимо от наследования или явного списка; неиспользуемая глобальная настройка не меняет расчётный хеш.

В resolved outputBuffers заменяет прежний единый outputBuffer. outputCapacity(station, materialId), как inputCapacity, возвращает ёмкость конкретного материала. simulation.ts использует её для прямой передачи и частичной выгрузки held→output. Проверка начального запаса, blockedBy снимка и FlowDiagram также выбирают фактический материал. Пример A infinite/B 0 работает одновременно: A остаётся в своём output, B напрямую идёт к получателю. При B 0.5 возможно удержание остатка B при заполненном выходе. Материалы не смешиваются в одном общем лимите.

Версия движка 0.17.0 отмечает новый расчётный контракт. Snapshot остаётся 12: его поля не менялись. Приложение 0.1.0, исходная конфигурация/RunConfig 1 и RNG counter32-fixed-lognormal-1 прежние. Изменение конфигурации аддитивное, прежние входы компилируются. Сохранённых прогонов и импорта для продолжения нет; миграции несуществующих сохранений не добавлялись. В конфигурации движка наследование доступно, новой панели нет до № 61.
